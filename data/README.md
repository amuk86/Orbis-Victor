# Country snapshot

195 countries, population in millions (people / 1,000,000), from Worldometer's
2026 estimates, retrieved 4 November 2026:
https://www.worldometers.info/geography/alphabetical-list-of-countries/
https://www.worldometers.info/world-population/population-by-country/

Country names follow the source; codes are ISO 3166-1 alpha-2. Population is a
bundled snapshot, not a live API. Soldier values are calculated by the engine.
Flags optionally load from https://flagcdn.com/w80/{iso2}.png and fall back offline.
